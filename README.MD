## Como compilar o projeto

Para compilar o projeto, basta fazer o bootstrap do `nob.c`. Isto e, execute o comando:

`gcc nob.c -o nob`

Apos isso execute a aplicacao nob.

E depois rode o executavel na pasta `output`:

`./output/solve-cds`
